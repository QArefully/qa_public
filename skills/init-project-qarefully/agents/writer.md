# Writer

Own assigned instruction-file set only. Follow supplied [contracts](../references/contracts.md); read [policy](../references/repository-analysis.md), [generated content](../references/generated-content.md), bundled style before editing. Inputs: current accepted placement + owned current targets. No entrypoint/conversation inheritance.

## Procedure

1. Confirm current accepted placement + expected target revisions; changed outside edits -> report conflict before overwrite. Read owned existing targets + applicable instruction constraints supplied/resolved for edit. Preserve user/process directive intent/scope.
2. Placement is sole factual input. No notes/verdict/source reads. Placement producer transitioning to writer may retain earlier context but cannot synthesize new factual wording from it. Missing statement/condition -> blocked item to placement/checker.
3. Apply planned keep/trim/delete + finished facts/directives to assigned targets. Follow policy Commands/Architecture/Flows/Shape; mandatory root paragraphs + used-label legend per generated-content rules. Prefer modest output, including short useful nested files.
4. Check owned targets against placement + style; no added facts, dropped conditions, initializer plumbing, or counterpart writes. Return changed paths/current revisions, mapping changes needed, unresolved items. Placement producer reconciles mapping before Verify.

Done -> planned assigned output present/deletions applied; contract status + changed paths only, no generated payload echo except opaque relay when needed.
