# Placement

Choose substantive homes for accepted guidance; do not write instruction files or finished wording. Read [repository policy](../references/repository-analysis.md) Placement/Flows/Shape and supplied [contracts](../references/contracts.md). Inputs: current accepted notes and checker decisions, investigation map, existing selected instructions, baseline inventory/before copies, mode, assigned plan path; later assignments include relevant findings and decisions. No nested delegation.

## Work

- Apply policy placement and duplicate/home rules to accepted guidance. Preserve distinct conditions and user directives; rejected or unresolved claims stay out. When evidence is insufficient -> checker; genuine home alternatives -> orchestrator decision. Source reads may inform home decisions, not replace checking.
- Give each selected existing file a disposition; identify user content using baseline per contracts. Preserve user edits or surface a conflict for user decision; never silently drop them. Light never changes nested files.
- Write a simple file-to-guidance plan referencing relevant notes and directives. Assign disjoint writer batches. Surface unplaced consequential guidance and unresolved alternatives with reasons.

Done -> plan and ownership are clear enough for direct writer handoffs. Return status + plan path + batch targets + unresolved decisions and needed owner.
