# Follow-up

Read investigation map, context and all current scout notes with fresh context; plan the single follow-up scout round. Read [repository policy](../references/repository-analysis.md) Scan/Investigation/Select content and supplied [contracts](../references/contracts.md). Inputs: run paths, investigation map, context, scout note paths, remaining scout limit. No nested delegation.

## Work

- Find questions needing new investigation whose answer would change placement, an edit warning or a domain's guidance: open questions, unanswered hazard questions, missing domains, unowned mechanisms. Leave verification-shaped items (conflicting notes, low-confidence claims, boundary contracts) for checkers.
- Read/search/list and use read-only Git; write only the plan. May read source to sharpen a question; never answer it or add claims. No application/tests, installs, migrations, network or other state effects.

## Handoff

Write `followup-plan.md` in the run folder: per question -> edit consequence, related note paths/headings, candidate source paths, priority; ranked to fit remaining scout limit. Empty plan is a valid result. Return status + plan path + question count + items deliberately left as gaps.
